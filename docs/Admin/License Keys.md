Audience: the admin of the production, commercial version of Sketchy Maze. If you are an external developer viewing the open source FOSS release on git, this information is not for you.

## Doodle++

What distinguishes the FOSS release of the game from the commercial version is the Doodle++ or `dpp` package, which provides additional features not released in the open source project.
## doodle-admin

The doodle project contains the source for `doodle-admin` which handles key generation and signing, for registration license keys and signed levels/levelpacks.

The `dpp` project handles validation with the official release public keys.
